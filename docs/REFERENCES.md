# Sumber Bacaan dan Dokumentasi

Referensi utama proyek:

1. anshsahu111, [Laptop Specifications and Prices Dataset, Kaggle](https://www.kaggle.com/datasets/anshsahu111/laptop-specifications-and-prices-dataset).
2. TensorFlow, [Documentation](https://www.tensorflow.org/).
3. Keras, [Keras API](https://keras.io/).
4. KerasTuner, [Documentation](https://keras.io/keras_tuner/).
5. scikit-learn, [Common Pitfalls](https://scikit-learn.org/stable/common_pitfalls.html).
6. Hugging Face, [Static HTML Spaces](https://huggingface.co/docs/hub/spaces-sdks-static).

Materi kuliah W01–W05 digunakan untuk MLP, preprocessing, optimasi, regularisasi, dan tuning. Topik CNN di W06–W07 tidak diimplementasikan karena dataset berbentuk tabular. Sumber lengkap juga tercantum pada daftar pustaka laporan.
