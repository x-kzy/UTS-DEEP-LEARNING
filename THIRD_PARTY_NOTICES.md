# Data dan Komponen Pihak Ketiga

- Dataset dari **Kaggle / anshsahu111**: [Laptop Specifications and Prices Dataset](https://www.kaggle.com/datasets/anshsahu111/laptop-specifications-and-prices-dataset). **Lisensi dan ketentuan distribusi data harus dicek pada halaman Kaggle** sebelum mendistribusikan data mentah. ZIP ini tidak memuat dataset penuh.
- TensorFlow/Keras, KerasTuner, scikit-learn, Pandas, NumPy, Matplotlib, Seaborn dan Hugging Face tunduk pada lisensi masing-masing.
- Screenshot dari Space **Xkazuya/LAPTOP-CLASSIFIER** merupakan gambar pengujian yang dibagikan anggota tim pada 9 November 2026. Gambar dokumentasi bukan pengganti verifikasi kinerja model.
- Berkas `LICENSE` yang sudah ada pada repository GitHub **dipertahankan** oleh skrip push. Lisensi source code tidak otomatis berlaku untuk dataset Kaggle.
