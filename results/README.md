# Bukti yang Tersimpan

- [`recorded/MANIFEST.json`](recorded/MANIFEST.json) mencatat checksum notebook sumber, lokasi output, daftar grafik, dan 30 tabel HTML yang berhasil diekstrak.
- [`recorded/tables/`](recorded/tables/) memuat tabel CSV yang berasal dari output HTML notebook. Beberapa format tabel Keras memiliki indeks bertingkat; rujuk output asli untuk konteks.
- Bukti grafik ditempatkan di [`docs/images/`](../docs/images/) agar GitHub menampilkannya langsung.
- Bukti website ada di [`docs/huggingface/`](../docs/huggingface/) dan dijelaskan dalam [`docs/HUGGING_FACE.md`](../docs/HUGGING_FACE.md).

**Tidak ada hasil training baru yang diklaim.** Paket ini adalah dokumentasi dari keluaran notebook terlampir dan screenshot pengujian yang sudah dikirim pengguna.
